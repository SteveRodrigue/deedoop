Changes to your files

deedup only reads your disks until you turn this on. Even then, nothing happens until you confirm a list of changes on the Changes screen, and every file is checked again just before it is touched.

Container access to /mnt: {% if gate.writable %}read-write{% else %}read-only To allow changes, edit the container and set the /mnt path's access mode to read/write.{% endif %}
