# Roadmap

What may come next for deedoop. Nothing here is promised or scheduled; the order
can change after testing on a real array. What has shipped is in
[CHANGELOG.md](CHANGELOG.md).

## Next

- **Takeout auto-detect.** Setup would list "Possible Takeout folders found"
  (folders holding `takeout-*.zip` or `Takeout/` trees) with an **Add** button
  each, instead of adding them by hand. An idea, not decided yet.

## Later

- **Community Applications package.** A public Unraid template so deedoop can be
  installed from Community Applications.

## Not yet

- **Publishing.** The repository and the `ghcr.io/steverodrigue/deedoop` image stay
  private until deedoop has been tested on a live array. Until then it is
  installed from the template in this repository
  ([docs/install-unraid.md](docs/install-unraid.md)), and there is no Community
  Applications submission and no GitHub release.
